# Product: Haunt Any Page

- A small Manifest V3 browser extension for the Kiroween 2026 hackathon (category: Costume Contest).
- One click turns the open website into a haunted version (dark candle-lit palette, drifting fog, flying bats, old-book font, optional candle flicker). A second click restores it exactly.
- The visual reference is `concept/haunt-any-page.html`. When in doubt about the look, match it.
- Keep it small. No frameworks, no bundler, no build step, no runtime dependencies. Plain ES modules and CSS.
- Out of scope: accounts, servers, analytics, sharing, sound, extra themes, Firefox/Safari packaging, options page.
- Everything in the repository (code, comments, docs, commit messages, UI text) is in English.
- Source of truth for behavior: `.kiro/specs/haunt-any-page/requirements.md`. Do not add features that are not in it.
